# HRIS System

Sistem Human Resource Information System (HRIS) berbasis web yang dibangun dengan Go (Gin) dan Next.js. Platform SaaS untuk manajemen SDM perusahaan di Indonesia yang mencakup penggajian, kehadiran, rekrutmen, penilaian kinerja, hingga integrasi AI untuk HR automation.

---

## Tech Stack

**Backend**
- Go 1.22 · Gin v1.9.1 · GORM v2
- PostgreSQL 16.2 · MongoDB 7.0 · Redis 7.2
- RabbitMQ 3.13

**Frontend**
- Next.js 14.2 · TypeScript 5.4 · TailwindCSS 3.4
- shadcn/ui · TanStack Query v5 · Zustand v4.5
- React Hook Form v7 · Zod v3 · Recharts v2.12

**Infrastruktur**
- Docker 26 · Docker Compose v2.24
- Nginx 1.25 · MinIO · GitHub Actions
